# PS4 data sources

MRTSSM4453USN.csv is the unadjusted U.S. liquor store sales series from the Census Bureau via FRED. The analysis keeps January 1992 through December 2019.
https://fred.stlouisfed.org/series/MRTSSM4453USN

fredqd_2026-09.csv and fredmd_2026-09.csv are the two September 2026 Canvas files. The duplicate suffix on the downloaded quarterly filename is removed in this folder. Both course files match the data used for the reference run byte for byte.

The St. Louis Fed distributes FRED-MD_updated_appendix.pdf inside the FRED-MD Appendix archive. A copy of that public PDF is in reference/. The helper file factor_series_key.csv supplies readable names for the correlation table. Data transformations for this assignment use the codes in the September 2026 data files.
https://www.stlouisfed.org/research/economists/mccracken/fred-databases

DNDGRG3M086SBEA is the PCE nondurable goods chain-type price index.
https://fred.stlouisfed.org/series/DNDGRG3M086SBEA
